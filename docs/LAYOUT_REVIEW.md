# 전체 화면 레이아웃 검토 · 2026-10-13

교사 한 화면 투사·학생 종이 참여, 고등학교 수준 기사, 독립적인 원인/환율 판단과 최초 답안 보존을 기준으로 검토했다. 기존 화이트·블루·Pretendard와 상황 SVG를 유지한다. 한 화면에서 학생이 볼 핵심과 교사 조작을 구분하고, 같은 대안을 모둠마다 반복하는 구조를 줄인다. 자료의 난도를 낮추거나 빈 공간을 추가 설명으로 채우는 방식은 적용하지 않는다.

## 화면별 판단과 반영

| 화면 | 문제·판단 | 반영 |
| --- | --- | --- |
| 입장 | 기존 제목·환전 그림의 구도는 유지할 수 있으나 좁은 화면에서 활동 순서가 어색하게 줄바꿈 | 작은 화면의 순서를 2×2로 정렬 |
| 설정 | 단계명과 제목이 중복되어 시작점이 무거움 | 제목을 ‘수업 준비’로 정리하고 반복 단계 띠 제거 |
| 규칙·제출 연습 | 선택 연습은 필요한 안내지만 상단 배점·단계 설명이 중복 | 연습과 채점 기준 유지, 공통 중복 띠 제거 |
| 뉴스 활동 | 두 문단 기사는 고등학교 판단 근거이며 720p에서도 읽을 수 있음 | 전문·110초·짧은 질문 유지, 진행 영역을 내용 뒤에 배치 |
| 모둠 답안 입력 | 8모둠에 선택 버튼 48개가 반복되고 중첩 스크롤 발생 | 활성 모둠의 2×2 원인·환율 2개와 전체 모둠 요약으로 변경. 요약 클릭·↑/↓ 연동 |
| 최초 답안 확인 | 슬래시로 이은 답안과 넓은 빈 공간, 새 배치의 8모둠 하단 가림 | 원인/환율을 두 줄로 분리한 2열 목록, 낮은 PC 행 간격 축소. 해설 전 ‘입력 수정’ 유지 |
| 해설 1 | 긴 거래 문장을 가장 굵게 표시하고 미공개 영역이 크게 차지 | 짧은 거래 결론과 근거 설명의 위계 분리, 다음 단계는 간결하게 표시 |
| 해설 2 | 앞 단계 문장이 새 수요·공급 변화를 압도 | 그래프를 먼저 배치하고 현재 단계만 강조. 환율/균형점은 계속 비공개 |
| 해설 3 | 모든 설명의 같은 굵기, 작은 화면에서 그래프가 뒤로 밀림 | 그래프와 현재 환율 결론이 먼저 읽히도록 조정. 이전/P와 점수 별도 공개 유지 |
| 모둠 결과 | 적은 모둠의 행이 지나치게 커짐 | 행 높이 상한 144→96px. 결과 비교와 선택 모둠 피드백 구조 유지 |
| 개인 수정 | 긴 제목·반복 안내, 선택 기록에 입력 버튼이 다시 반복 | ‘개인 기록 고치기’로 간결화. 선택 기록은 동일한 활성 모둠 입력으로 변경 |
| 개인 확인 A/B | 전문과 종이 판단 지시는 필요한 정보 | 기사·질문 유지, 공통 단계 띠와 불필요한 영역 성장 제거 |
| 개인 확인 해설 | 거래 설명·원인·환율이 모두 굵어 대비가 약함 | 거래 근거는 보통 굵기로 조정. 공개 후 같은 화면으로 돌아가는 이전 버튼 제외 |
| 최종 정리 | 제목이 길고 1024px에서 원리와 결과가 세로로 쌓임 | 제목 간결화, 중간 PC도 원리와 결과 2열로 함께 표시 |
| 상단바 | 교사 도구의 박스 강조가 본문과 경쟁 | 가이드·전체 화면을 조용하게 표시하고 좁은 화면 버튼 간격 조정 |
| 메뉴 | 넓은 버튼 묶음이 본문을 밀거나 가림 | 우측의 작은 세로 메뉴로 고정 |
| 교사용 가이드 | 큰 도입부가 실제 준비 안내를 아래로 미룸 | 도입부 높이 축소, 새 모둠 입력 방식 안내 반영 |
| 단축키·뉴스·설정 팝업 | 내용과 함께 닫기 버튼이 스크롤 밖으로 사라짐 | 내용만 스크롤하고 닫기 영역은 계속 표시. 뉴스의 중첩 박스 제거 |
| 개인 기록지 | 종이의 반복 선택어는 학생 응답에 필요 | 웹 입력과 구분해 유지. 실제 인쇄 버튼의 A4 양면·흑백 출력 재검증 |

숨긴 fieldset legend의 위치 기준이 없어 최상위 문서에 유령 스크롤을 만드는 원인도 수정했다. 입력 완료·미제출·선택 요약은 저장 성공 후 즉시 갱신하며, 모둠 변경만으로 답안이 바뀌지 않는다. 마우스를 올린 요약과 실제 활성 모둠은 서로 다른 강조를 사용한다.

## 검증과 한계

수정 전 시각 검토와 기계적 검토를 독립적으로 수행했다. 수정 후 전체 단계 91개 배치(360~1920px, 8자 모둠 이름), 활성 입력·수정 36개 배치(2/5/8모둠, 390/1024/1280/1920px), 전체 기사 32개 배치, 가이드 8개 크기를 확인했다. 2/8모둠의 모든 단계·미제출·메뉴·팝업은 164개 DOM 측정과 16개 포커스 복귀 기록으로 별도 확인했다. 가로 넘침·그래프 글자 잘림·PC 진행 버튼 가림·팝업 닫기 가림이 없고, 8모둠 최초 답안의 마지막 환율까지 진행 버튼 위에 표시된다.

핵심/그래프 23개 검사, 전체 수업 PC 8모둠 6라운드/휴대폰 2모둠 4라운드, 키보드·해설 이전·리허설·저장 경합/복원 검사를 통과했다. 교실 시뮬레이션 두 번의 예상 점수·첫 답안 불변·수정·개인 확인·버튼 접근을 확인했다. 시뮬레이션의 진행 클릭 52/37회는 단계 전환 횟수이며 새 모둠 요약 클릭을 포함한 총 조작 횟수는 아니다.

웹 인쇄 버튼으로 4/6라운드 각각 정확히 A4 두 쪽을 출력하고 수정 전후의 8면 렌더가 픽셀 단위로 같음을 확인했다. 별도 PDF는 전달하지 않는다. JS 구문·공백·정적 빌드 및 Impeccable layout 탐지 결과 `[]`를 확인했다. 시각 증거·측정 원본은 저장소 밖 `design/verification/all-layout`에 보관한다.

작은 화면은 교사 준비·확인용으로 세로 스크롤하며 실제 학생의 모바일 입력을 제공하지 않는다. 실제 교실 뒤쪽 좌석의 투사 가독성, 프린터 결과, 새 입력 구조의 교사 조작 시간은 아직 현장에서 측정하지 않았다. GitHub/운영 배포 상태는 `PROJECT_STATE.md`의 최신 기록을 따른다.
