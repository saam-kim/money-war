## 디자인 방향과 기준

현재 디자인은 뉴스 분석 수업에 충분히 구체적이다. 뉴스의 큰 읽기 영역, 원인·환율·원화 가치의 독립 입력, 그래프와 인과 해설의 병치, 별도 점수 공개가 이 수업의 성격을 만든다. 기존 시각 체계를 보존하며 학생의 읽기와 교사 조작을 개선했다.

검토 계획은 다음 기준으로 세웠다. 새로운 시각 세계를 만드는 작업이 아니므로 자동 생성 팔레트로 기존 기준을 교체하지 않았다.

## 강점

1. 뉴스 본문과 제목이 중심이며, 개인 판단과 토의에서 읽기 맥락을 유지한다.
2. 정답 공개 전 선택은 중립적이고 세 판단을 독립적으로 기록한다. 네 연결을 누적 공개한 뒤 별도로 점수를 확인한다.
3. 최초 답안과 수정 기록을 구분한다. 공동 순위와 요소별 점수는 고칠 연결을 찾는 데 사용하고, 최종 화면은 원리를 먼저 보여 준다.

## 인지 부하와 사용자의 경험

학생의 뉴스 해석·독립 인출·토의·네 연결 추론·새 사례 적용은 의도된 학습 부담이다. 자동 반대 방향 채우기나 모둠 답 복사로 이를 없애지 않았다. 각 판단은 4/2/2개 선택으로 나뉘므로 전체 화면의 라디오 수를 한 번짜리 선택 수로 해석하지 않는다.

줄인 것은 교사에게 불필요했던 작업이다. 타이머 조작 뒤 키보드 위치를 다시 찾는 일, 0초 의미를 추측하는 일, 결과표와 근거를 오가며 진행 버튼을 찾는 일을 줄였다. 최초 검토에서는 위계와 상세 작업에 관련된 인지부하 체크 2/8개가 보완 대상이었다.

- 처음 쓰는 교사: 종료 상태와 다음 행동이 보이고 메뉴·대화상자에서 빠져나올 수 있다.
- 뒤쪽 학생: 거래 행동·시장·환율·원화 가치와 그 이유를 더 큰 글자로 읽는다. 실제 후방 가독성은 교실에서 확인해야 한다.
- 키보드 교사: 라디오의 방향키, 타이머의 Enter, 메뉴·dialog Escape, 모둠 상세의 포커스 위치를 유지한다.

동시 응답 뒤 설명을 하나씩 확인하고, 결과에서 고칠 연결을 찾으며, 최종 원리를 먼저 보여 주는 흐름을 유지했다. 경쟁 결과가 학습의 마무리를 대신하지 않도록 했다.

코어·그래프 15개 테스트, 8모둠·6라운드와 2모둠·4라운드 실제 UI 흐름, 360–1920px 138개 상태를 검사했다. 새 타이머·메뉴·dialog·상세 동작은 회귀 검사에 추가했다. 마지막 선택 모둠 노출 수정은 추가 시각 검토 대신 해당 기능의 좌표·포커스·진행바를 좁게 확인했다. 학생 점수·독립 판단·공개 순서는 그대로다.

CLI detector는 1회 실행해 0건이었다. 브라우저 5뷰는 4뷰 0건, 토의뷰 1건이었다. `text-occlusion`은 닫힌 `.sentence-template > p`를 가시 본문으로 간주한 오탐이었다. 자동 검사 결과와 시각적 품질 판단을 구분했다.

남은 Priority Issue는 P3 두 가지다. 교실 주 화면의 진행을 막는 문제는 아니다.

1. 좁은 최종 화면에서 표를 좌우로 움직일 수 있다는 안내를 추가할 여지가 있다. 실제 합성 터치 스크롤은 작동한다.
2. 좁은 최종 화면에 보조 버튼이 세 개 있으면 인쇄 버튼 문구가 자연 줄바꿈한다. 다음 모바일 전용 개선에서 버튼 행 배치를 다듬을 수 있다.

실제 교실 프로젝터·뒤쪽 좌석, 실제 프린터·휴대폰 터치·보조공학, 실제 브라우저 200% 및 OS 문자 확대는 미검증이다. 683×384는 확대에 해당하는 CSS viewport 등가 검사이며 실물 검증으로 표현하지 않는다. 개인 기록지 1쪽, 8모둠 결과 2쪽의 Chromium A4 출력은 확인했다.

## 후속 배치·리허설 반영 · 2026-10-07

사용자 요청에 따라 기존 팔레트·서체·그래픽과 학습 순서를 유지하며 콘텐츠 너비·간격·표 밀도를 조정했다. 일반 수업 내용과 진행 영역은 최대 1280px, 제출 방식 연습·최초 답안 확인·설정은 최대 1120px로 정렬한다. 입력 버튼은 기존 크기를 유지하고 상태를 한 행에 모아 최소 5개 모둠을 투사 화면에서 함께 확인한다. 완료 수는 표 위에 고정된 위치에 표시한다. 1024px 구간에서도 뉴스와 활동 안내를 나란히 놓고, 큰 최종 화면의 원리와 모둠 결과는 두 열로 보여준다.

입장 화면에 교사용 `수업 리허설`을 별도로 두었다. 리허설에서는 수정 가능한 예시 답안으로 전체 흐름을 연습하며 종료 버튼과 연습 상태를 표시한다. 실제 저장 기록을 변경하지 않고 종료할 때 최신 실제 수업으로 복귀한다.
