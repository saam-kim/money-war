## 학습 목표와 참여 환경

대상은 환율의 의미와 외환 수요·공급을 배운 고등학교 경제 학생이다. 학생은 뉴스의 거래 주체가 달러를 사는지 파는지, 거래가 늘거나 줄었는지 설명하고, 수요·공급 변화 → 원/달러 환율의 방향을 새 사례에 적용한다. 사용자 최신 지시에 따라 원화 가치의 별도 판단·입력·채점·해설 단계를 제거했다.

- 교사 PC 한 화면을 프로젝터로 투사한다. 학생은 개인 기록지와 모둠 답안판으로 참여한다.
- 학생 패드·QR 입장·학생 계정·서버 동기화는 필요 없다. 교사 한 탭에서 진행한다.
- 모둠 수 2~8, 기본값 5. 모둠 이름 최대 8자, 같은 이름은 번호로 구분한다.
- 기본 6라운드 약 30분 / 단축 4라운드 약 20분. 시간은 운영 예상이며 실제 교사 입력 시간을 측정한 값이 아니다.
- 정적 HTML/CSS/JavaScript, 로컬 Pretendard와 OFL 라이선스. 외부 서비스·빌드 없이 실행한다.

## 교사 키보드 조작

교사는 N/P로 다음·이전 단계, T와 +로 타이머 정지·시작과 10초 추가를 조작한다. 답안 입력에서는 1~4로 네 원인 문구를 왼쪽부터 선택하고 5/6으로 환율 상승/하락, ↑/↓로 모둠 이동, 0으로 미제출을 기록·해제한다. 현재 입력 모둠을 표시하며 마우스 선택과 연동한다. 답안·수정 입력 중 ↑/↓는 라디오의 선택값을 바꾸지 않고 모둠만 이동하며 첫·마지막 모둠에서는 멈춘다. 결과 화면의 1~8은 해당 모둠 상세를 연다. V는 뉴스, R은 수정 입력이며 화면에 해당 버튼이 있을 때만 작동한다.

H 또는 메뉴의 단축키 안내에서 목록과 사용 옵션을 제공한다. 사용 여부는 현재 창에서만 유지한다. 단축키는 한글 입력 상태의 물리 키 위치로 해석하지만 문자 입력·IME 조합·메뉴·팝업·저장 중·저장 충돌에서는 수업 조작을 차단한다. 키 반복으로 여러 단계를 건너뛰지 않으며 기존 확정·해설 공개·채점·저장 보호 규칙과 같은 버튼 동작을 사용한다. 학생의 종이 응답 방식은 그대로다.
