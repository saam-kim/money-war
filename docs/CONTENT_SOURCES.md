# 뉴스·해설의 교과서 근거

정리일: 2026-10-06. 기존 활동 기획서의 교과서 연결표와 현재 `js/data.js`를 기준으로 정리했다. **쪽수는 교과서 인쇄 쪽수**이며 PDF 뷰어 페이지 번호가 아니다. 이번 수정에서 PDF 전체를 다시 렌더해 모든 쪽수를 재검수한 것은 아니다.

참고 교과서는 사용자 제공 「[비상교육] 고등 경제(유종열)」와 「고 경제(김태환)」다. 판본·성취기준 번호를 추정하지 않는다. 원본 PDF·추출 텍스트·실학생 기록은 저장소에 포함하지 않는다.

## 개념 근거 식별자

`js/data.js`의 `sourceRefs`는 아래 개념 근거를 가리킨다. 교과서의 사례를 그대로 복제했다는 의미가 아니다.

| 식별자 | 개념 | 비상교육·유종열 | 김태환 |
| --- | --- | --- | --- |
| `fx-transaction` | 국제 거래에서 외환이 필요한 이유, 상품·서비스·투자 | 151~152, 156쪽 | 161~162, 189쪽 |
| `fx-value` | 환율의 의미와 원화 가치의 반대 방향 | 175~177쪽 | 191~192쪽 |
| `fx-market` | 외환 수요·공급, 증가·감소와 균형 환율 | 178~180쪽 | 193~195쪽 |
| `fx-application` | 사례를 수요·공급 곡선 이동과 환율 방향에 연결 | 181쪽 | 195, 200쪽 |
| `fx-life` | 같은 환율 변화가 개인·기업에 미치는 다른 영향 | 182~184, 188~189쪽 | 197~200쪽 |

핵심 설계는 김태환 교과서의 뉴스 탐구를 활용해 사건을 외환 시장 변화로 설명하는 것이다. 비상 교과서의 역할 비교는 생활 적용의 선택 확장으로 사용한다.

2026-10-06 사용자 결정으로 기본 답안과 평가의 범위를 원인·환율로 좁혔다. 원화 가치 관계는 아래 교과 내용 참고표에 보존하지만 앱의 선택·채점·기본 해설에는 포함하지 않는다. 이 범위 선택은 수업 운영 결정이며 특정 교과서가 원화 가치를 다루지 않는다는 뜻이 아니다.

2026-10-07 사용자 결정으로 학비 부담·급여 수입을 비교하는 생활 적용 화면도 제거했다. 교과서의 생활 영향 내용은 근거 자료에 보존하되 앱에서는 원인과 환율 방향의 반복 적용에 집중한다.

## 현재 뉴스와 적용 관계

아래 8문항은 교과서의 개념을 바탕으로 직접 구성한 **수업용 가상 사례**다. 실제 기사·현재 환율·시장 예측으로 제시하지 않는다. 전 문항에 다른 조건 일정, 원/달러 환율 기준을 적용한다.

| 뉴스 ID / 역할 | 국내 달러 거래의 변화 | 원인 → 환율 → 원화 가치 | 적용 근거 |
| --- | --- | --- | --- |
| `travel` / 라운드 1 | 여행사 현지 결제 확대, 원화 고객 대금으로 달러 마련 | 수요 증가 → 상승 → 하락 | 거래·시장·가치·사례 적용 |
| `study` / 라운드 2 | 학비·생활비 지급을 위한 달러 매입 감소 | 수요 감소 → 하락 → 상승 | 거래·시장·가치·사례 적용 |
| `content` / 라운드 3 | 콘텐츠 수출 대금 증가, 전액 국내 제작비용 원화로 환전 | 공급 증가 → 하락 → 상승 | 거래·시장·가치·사례 적용 |
| `visitors` / 라운드 4 | 미국 관광객의 달러→원화 환전 감소 | 공급 감소 → 상승 → 하락 | 거래·시장·가치·사례 적용 |
| `outward` / 라운드 5 | 국내 원화 자금을 미국 공사비 지급용 달러로 환전 증가 | 수요 증가 → 상승 → 하락 | 같은 수요 원리를 여행에서 해외 투자로 전이 |
| `inward` / 라운드 6 | 미국 기업이 한국 토지·시설 비용용 달러를 원화로 환전 증가 | 공급 증가 → 하락 → 상승 | 같은 투자 맥락에서 거래 방향의 차이 구분 |
| `coffee` / 개인 확인 A | 재고 누적으로 발주 감소, 원화 자금으로 달러 결제 | 수요 감소 → 하락 → 상승 | 유학과 다른 사례에서 수요 감소 인출 |
| `remittance` / 개인 확인 B | 해외 송금 달러의 국내 원화 환전 감소 | 공급 감소 → 상승 → 하락 | 관광과 다른 사례에서 공급 감소 인출 |

기본 6라운드는 네 변화 모두를 다루고 수요 증가·공급 증가를 투자 사례에 재적용한다. 단축형은 앞 네 라운드만 사용한다. 두 모드 모두 마지막 개인 A/B를 유지해 수요 감소와 공급 감소도 새 사례에서 확인한다.

2026-10-07 사용자 요청으로 8문항을 고등학교 경제 수준의 두 문단 기사로 개편했다. 경제적 배경·주체의 결정·결제 통화·자금 출처·국내 환전 행동을 읽고 학생이 달러 거래를 추론하게 한다. 본문에서 수요·공급 또는 환율의 정답을 직접 말하지 않는다. 후속 사용자 피드백에 따라 1인당 지출/가격 일정, 기존 달러 보유액 일정, 대체 자금 조달/사용 배제 등의 문제식 전제는 본문에서 제거했다. 다른 조건 일정은 기사 아래 공통 안내와 개인 기록지에 표시한다. 원화로 달러를 마련하거나 받은 달러를 원화로 바꾸는 실제 거래 내용은 판단 근거로 유지한다. 수요 감소와 공급 감소 및 같은 투자 맥락의 양방향을 비교하는 구성과 정답 코드는 유지한다. 실제 시점의 기사·통계·환율 예측을 인용한 것이 아니며 고등학교 교과 개념을 적용하도록 작성한 사례다.

## 교과 내용과 앱 운영 규칙의 구분

교과서 근거는 환율 단위, 외환 거래·수요·공급·균형, 원화 가치와 생활 영향이다. 다음은 이 앱에서 정한 운영·평가 규칙이며 교과서의 게임 규칙이나 학습 효과 연구 결과가 아니다.

- 개인 판단 → 모둠 토의 → 동시 답안판 공개, 교사 1화면.
- 라운드당 세 요소 각 2점, 36점/24점, 공동 순위.
- 달러 수요·공급의 증가·감소와 환율의 두 선택, 해설 3단계 뒤 별도 채점, 최초 답안과 수정 기록 분리.
- 예상 20/30분, 2~8모둠, 참고 타이머, 개인 확인의 비합산.

새 문항을 추가할 때 달러 매입/매각, 거래 증감, 결제·환전 조건을 분명히 적고 개념 근거 식별자를 연결한다. 달러가 유입됐다는 사실만으로 공급 증가를 단정하거나 반대 방향의 여러 요인 중 하나를 정답으로 단정하지 않는다. 기본 모형을 벗어나는 내용은 별도 근거 확인 후 심화로 구분한다.
