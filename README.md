# 머니워 · 뉴스로 이해하는 환율

고등학교 경제 수업에서 환율 변동의 **원인과 방향을 설명하고, 다른 사례에 반복해서 적용하는** 교사용 웹앱입니다. 교사는 화면 하나를 투사하고 학생은 개인 기록지와 모둠 답안판으로 참여합니다. 학생 기기·계정·별도 서버는 필요하지 않습니다.

현재 소스는 환율의 원인과 방향 학습에 집중하도록 재구성한 버전입니다. 개발·검증 상태는 [진행 기록](docs/PROJECT_STATE.md)에 정리했습니다.

확정 [수업 조건](docs/CLASSROOM_SPEC.md)과 [교과서·뉴스 근거](docs/CONTENT_SOURCES.md)를 저장소에 함께 보관합니다. 뉴스는 교과 개념에 적용하도록 만든 가상 사례이며 게임 점수·시간은 이 앱의 운영 규칙입니다.

## 실행

Vercel 운영 배포 대상 주소: **https://mwar.vercel.app**. 배포 상태와 검증 기록은 아래 진행 기록에서 확인합니다.

배포용 파일은 `node scripts/build.cjs`로 `dist/`에 생성합니다. 웹앱 파일과 글꼴만 포함하며 개발 문서·검사·수정 스크립트는 제공하지 않습니다. GitHub 소스 보관과 Vercel 배포는 별도 단계입니다.

`index.html`을 브라우저에서 열거나, 저장소 폴더에서 다음 명령으로 로컬 서버를 실행하세요.

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8766`에 접속합니다. 같은 브라우저와 같은 주소에서 사용하면 자동 저장한 기록을 이어갈 수 있습니다. 브라우저 저장을 차단한 환경에서는 안내가 표시되며 현재 창에서만 진행할 수 있습니다. 기존 v2 수업은 최초 답안을 보존하고 원화 가치 항목을 제외한 6점 기준으로 계산합니다. 불러올 때 이 변경을 안내합니다. 원본 v1 기록은 변환하지 않습니다.

## 수업 운영

1. 모둠 수(2~8), 모둠 이름, 기본 6라운드(약 30분) 또는 단축 4라운드(약 20분)를 설정합니다.
2. 개인 기록지를 인쇄하고 제출 방식을 연습합니다. 달러 수요 증가·감소 또는 달러 공급 증가·감소와 환율 상승/하락을 각각 판단합니다.
3. 뉴스 읽기 → 개인 판단 → 모둠 토의 → 답안판 동시 공개 → 교사 입력 → 최초 답안 확정 순서로 진행합니다.
4. 거래 행동 → 달러 시장 변화 → 원/달러 환율의 해설을 하나씩 공개합니다. 세 단계 뒤에 별도 버튼으로 모둠 결과를 봅니다. 뉴스 준비와 동시 공개 확인은 추가 화면 없이 진행하며, 모든 모둠의 답안판을 동시에 공개한 뒤 입력합니다.
5. 개인 기록에서 틀린 연결을 고칩니다. 앱의 모둠 수정 기록은 선택 사항입니다.
6. 마지막 두 개인 문항을 모두 푼 뒤 해설을 확인하고, 네 가지 원리와 모둠 결과를 정리·인쇄합니다.

개인 기록지는 **A4 한 장의 앞뒤(총 2쪽)**에 맞춘 흑백 양식입니다. 4/6라운드에 따라 표의 행 높이와 선택어 크기를 조절하고, 뒷면 두 사례는 남는 공간을 활용해 크게 배치합니다. 1쪽에는 라운드별 최초 판단과 해설 뒤 수정, 2쪽에는 두 개인 확인 문항을 둡니다. 원인·환율·거래 변화는 미리 쓴 문장의 선택어에 동그라미를 치고, 개인 확인에서는 뉴스 속 판단 근거에 밑줄을 긋습니다. 결과·정리 자료도 1쪽의 네 가지 원리와 모둠 결과, 2쪽의 개인 확인 해설로 나눕니다. 개인 기록지는 웹앱의 인쇄 버튼으로 출력하세요. 브라우저 인쇄에서 A4·배율 100%·양면(긴 쪽 넘김)을 선택하고 머리글/바닥글을 끄세요. 배경 그래픽은 꺼도 됩니다.

원/달러 환율은 **1달러를 사는 데 필요한 원화 금액**입니다. 뉴스와 그래프는 다른 조건이 같은 수업용 사례이며 실제 시장 예측이나 수치 시뮬레이션은 하지 않습니다.

## 기록과 점수

- 수요·공급 구분 2점 + 증가·감소 2점 + 환율 2점 = 라운드당 6점. 기본 36점, 단축 24점입니다. 원화 가치의 별도 입력·채점·해설 단계·기록지 칸은 없습니다.
- 원인과 환율은 독립적으로 입력합니다. 방향만 맞히거나 일부 원인만 맞혀도 해당 요소를 따로 채점합니다.
- 타이머 종료는 자동 제출·공개·이동을 일으키지 않습니다. 미제출은 교사가 직접 기록합니다.
- 최초 답안은 해설 시작 전까지 수정할 수 있습니다. 이후 수정 답안은 별도로 남고 최초 점수는 보존됩니다.
- 이전 이동·새로고침·결과 재열기로 점수가 더해지지 않습니다. 동점은 공동 순위(1위·1위·3위)로 표시합니다.
- 개인 확인은 모둠 점수에 합치지 않습니다. 초기화 및 새 수업 시작 시 기존 기록 삭제를 확인합니다.
- 교사는 한 탭에서 진행합니다. 다른 탭이 진행·초기화·새 수업을 시작하면 오래된 탭의 저장을 막고 `최신 기록 불러오기`를 표시합니다. 불러온 뒤 최초 답안과 공개 단계에서 이어갈 수 있습니다. Web Locks 지원 환경에서는 동시 저장도 직렬화하며 미지원 환경은 한 탭 운영이 필요합니다.

투사 화면에서는 진행 버튼이 별도 하단 공간에 표시됩니다. 결과표와 선택 모둠의 오답 설명은 나란히 보이며, `모둠 수정 기록`을 열면 입력 전용 공간으로 전환됩니다. 두 개인 문항은 모두 풀고 나서 거래 행동·달러 시장·환율을 한 화면에서 비교합니다.

첫 적용에서는 뒤쪽 좌석에서 뉴스·그래프가 읽히는지, 8모둠의 두 판단 입력 시간이 충분한지, 인쇄 기록지의 필기 공간을 확인하세요. 모둠 점수와 별개로 마지막 개인 확인의 **달러 거래 이유**를 수거해 개인 이해를 확인합니다. 약 20/30분은 실제 운영 전의 예상입니다.

## 교사 리허설

입장 화면의 **수업 리허설**을 누르면 설정 없이 5모둠·6라운드의 연습 수업이 열립니다. 입력 단계에는 정답·부분 오답·미제출 예시가 준비되어 있으며 직접 바꿀 수 있습니다. 뉴스부터 개인 확인과 최종 결과까지 실제 버튼으로 시험합니다. 실제 수업의 활동 안내·학생 제출 연습과 구분되는 교사용 기능입니다.

리허설은 창 안에서만 진행하고 실제 수업의 저장 기록·답안·점수에 반영하지 않습니다. 상단 **리허설 종료**나 **처음으로**를 누르면 최신 실제 수업 기록으로 돌아갑니다. 메뉴의 **리허설 다시 시작**은 연습만 초기화하고, 새로고침하면 연습은 끝납니다. 리허설 결과 인쇄에는 예시 답안 결과임을 표시합니다.

큰 화면의 수업 내용은 최대 1280px 안에 모으고, 최종 화면은 관계표와 모둠 결과를 함께 보여줍니다. 입력 완료 수는 입력표 위에 표시합니다. 작은 화면에서는 세로로 읽고 필요한 표 영역만 스크롤합니다.

## 키보드로 진행

수업 화면의 버튼에 단축키를 표시합니다. 한글 입력 상태에서도 같은 위치의 키를 누르면 됩니다. 메뉴의 **단축키 안내** 또는 **H**로 전체 목록을 확인하고 사용을 끌 수 있습니다. 사용 여부는 현재 창에서만 유지하며 새로고침하면 다시 켜집니다.

| 조작 | 단축키 |
| --- | --- |
| 다음 / 이전 단계 | N / P |
| 타이머 정지·시작 / 10초 추가 | T / + |
| 달러 수요 증가·감소 / 공급 증가·감소 | 1·2 / 3·4 |
| 환율 상승 / 하락 | 5 / 6 |
| 이전 / 다음 모둠 | ↑ / ↓ |
| 미제출 기록·해제 | 0 |
| 결과에서 모둠 상세 보기 | 1~8 |
| 뉴스 다시 보기 / 수정 기록 열기·닫기 | V / R |
| 단축키 안내 / 팝업 닫기 | H / Esc |

답안 입력에서는 선택된 모둠을 표시하며 마우스로 선택한 모둠과 연동합니다. 원인 1~4는 버튼의 왼쪽부터 순서대로 대응합니다. 수정 입력은 `모둠 수정 기록`을 연 뒤 사용합니다. 이름 입력·메뉴·팝업·저장 충돌 중에는 수업 단축키를 막고, 미완료 답안의 확정과 공개 뒤 원본 답안 변경은 기존 규칙대로 차단합니다. 답안 입력과 수정 입력의 ↑·↓는 모둠만 이동하며 답안을 바꾸지 않습니다. Tab·Enter·Space와 ←·→의 기존 버튼·라디오 조작도 유지합니다.

## 파일과 검증

```text
index.html           화면과 교사 도구
css/style.css        투사·작은 화면·인쇄 스타일
js/data.js           구조화된 뉴스, 원인, 개인 문항
js/core.js           상태 전환, 채점, 타이머, 저장 검증
js/storage.js        저장 충돌 확인과 탭 간 쓰기 잠금
js/graph.js          외환 시장 곡선과 이동 표시
js/print.js          개인 기록지와 결과 인쇄
js/app.js            화면 표시와 입력 처리
assets/              로컬 Pretendard 글꼴과 OFL 라이선스
tests/               학습 흐름·상태·그래프·브라우저 검증
docs/PROJECT_STATE.md  재개용 진행·검증 기록
docs/CLASSROOM_SPEC.md  확정 수업 조건과 운영 정책
docs/CONTENT_SOURCES.md 교과서 개념·뉴스별 근거 연결
```

앱 실행에 빌드나 패키지 설치는 필요하지 않습니다. 핵심 로직은 Node.js의 기본 테스트 도구로 검사합니다.

```powershell
node --test tests/core.test.cjs tests/graph.test.cjs
```

Playwright와 Chromium이 준비된 환경에서는 위 로컬 서버를 띄운 뒤 브라우저 검증을 실행합니다. 이 도구는 검증용이며 앱에는 포함되지 않습니다.

```powershell
node tests/browser.cjs
node tests/storage-browser.cjs
node tests/layout.cjs
node tests/classroom-simulation.cjs
node tests/rehearsal-browser.cjs
node tests/keyboard-browser.cjs
```

선택 환경 변수: `TEST_URL`(기본 localhost:8766), `PLAYWRIGHT_MODULE`(Playwright 모듈 경로), `CHROME_PATH`(Chrome 실행 파일), `QA_OUTPUT_DIR`(스크린샷·PDF·레이아웃 보고서 경로). 기본 출력은 OS 임시 폴더의 `money-war-qa`입니다. 교과서 PDF·추출 텍스트·학생 개인 기록은 저장소에 포함하지 않습니다.
